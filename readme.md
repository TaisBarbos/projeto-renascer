# Projeto Renascer Profissional 🌸

Plataforma web desenvolvida com foco em acolhimento, orientação e resgate de autonomia profissional para mães solo. O projeto une design humanizado (UI/UX) com interatividade para engajar e conscientizar o público-alvo.

## 🚀 Tecnologias Utilizadas
O projeto foi construído seguindo boas práticas de separação de responsabilidades e desenvolvimento front-end:
* **HTML5:** Estruturação semântica e limpa do conteúdo.
* **CSS3:** Estilização modular com design system próprio (cards em relevo, paleta de cores acolhedora) e **Media Queries** para responsividade mobile.
* **JavaScript (ES6+):** Manipulação dinâmica do DOM para o sistema de quiz interativo em tempo real.

## 💡 Funcionalidades
* **Seção de Identificação de Dores:** Validação empática dos desafios enfrentados na rotina.
* **Quiz Interativo de Autoavaliação:** Ferramenta dinâmica onde a usuária clica em seu principal desafio atual e recebe uma resposta acolhedora personalizada instantaneamente.
* **Design System Consistente:** Componentes padronizados em formato de cartões com bordas de destaque e sombras suaves.
